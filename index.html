⚡ 快速安装

确保已安装 Git, JDK 21, Maven

git clone git@github.com:qmjy/Chilo.git
cd Chilo
mvn clean package

启动服务

cd target
java -jar Chilo-xxx.jar --dataPath="你的数据目录"
🌐 访问 http://localhost:10101 查看系统页面

资源目录结构示例

data/
├── assets/ (fonts, sprites)
├── styles/ (world.json)
├── poi/ (xxx.osm.poi)
├── osm.pbf/ (Chengdu.osm.pbf)
├── gpkg/ (chengdu.gpkg)
├── tilesets/ (Chengdu.mbtiles, .tpk)
└── OSMB/ (China.geojson)
